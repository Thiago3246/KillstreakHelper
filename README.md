This script helps you farm Kills and Slaps really fast by loop teleporting your alt to you and resetting! (Fully automated)

**It's very stable, but if any bugs occur, click "Stop" and then "Start" again to restart the teleportation**

HOW TO USE:

1. Get an alt account
2. Execute the script on the alt account
3. Enter your main account’s name (exact or partial name/display name; it's remembered for next time)
4. Click the "Start" button
5. The alt already has built-in anti-AFK. On your **main** account, execute Infinite Yield and type the ```antiafk``` command
6. Set up an Auto Clicker on your main account to start farming

With this script you can:

- Use 2 accounts to farm Kills and Slaps AFK in a safe place (specific coordinates)
- Easily complete Kills and Slaps mastery quests simultaneously (for Killstreak or any other glove)
- See the live status and how many times the alt died (= kills for your main)
- The script stops automatically if your main account leaves the server
